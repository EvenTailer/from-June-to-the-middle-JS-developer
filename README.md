# from-June-to-the-middle-JS-developer

Интерактивный учебник по JavaScript: путь от новичка до middle-разработчика.

20% теории и 80% практики: короткие Q&A-карточки, тесты по модулям и большая
библиотека задач, разбитых по темам-блокам.

## Что внутри

- **11 модулей** — HTML/CSS, Git, CLI, OOP и SOLID, HTTP, основы JavaScript,
  TypeScript, React, Redux Toolkit, React Router, Next.js.
- **630 вопросов с ответами** — только то, что реально спрашивают на собеседованиях
  и что нужно для работы, без воды.
- **389 практических задач** — в том числе 224 задачи-тренировки по 28 темам:
  циклы, функции, массивы, объекты, строки, числа, типы, асинхронность, DOM,
  ошибки, алгоритмы, Git, shell, ООП, HTTP, безопасность, TypeScript, React,
  хуки, формы, производительность, Redux, роутинг, Next.js, тестирование, туллинг.
- **Тесты по модулям** — по одному вопросу за раз, с разбором ответа и итоговым рейтингом.
- **Тренажёр** (`/practice`) — блоки практики с фильтром по сложности, подсказками
  и раскрываемым решением.

## Стек

React 19, TypeScript, Vite, React Router 7, Redux Toolkit, Oxlint.

## Скрипты

```bash
npm install     # установка зависимостей
npm run dev     # dev-сервер на http://localhost:5173
npm run build   # tsc -b + production-сборка
npm run lint    # oxlint
npm run preview # предпросмотр собранного проекта
```

## Структура

```
src/
  app/            роутер и каркас приложения
  pages/          страницы: главная, модуль, квиз, тренажёр
  widgets/        header, панель задач модуля, квиз
  entities/       доменные типы (модули, вопросы, задачи)
  shared/         контент, стор, i18n, UI-компоненты, стили
```

Прогресс (изученные вопросы, решённые задачи, лучшие результаты тестов, язык и тема)
хранится в `localStorage` под ключом `js-tutorial:state:v1`.

## Как учиться

1. Откройте модуль и пройдите вкладку **Обучение** — вопрос-ответ с примером кода.
2. Пройдите **Тест** — 10–35 вопросов с разбором.
3. Выполните **Практику** — задачи сгруппированы по темам, у каждой есть подсказка
   и готовое решение с объяснением.
4. Смешайте темы в **Тренажёре** — 28 блоков с независимыми задачами.
